# Lesson workspace

Use the creator's request and relevant installed skills to choose the teaching approach. Give the lesson a layout and interaction that fit its subject.

- Write a complete HTML page to `site/index.html`. Use inline CSS, JavaScript, and graphics that work in a sandboxed document.
- Use `./lesson-studio.png` for a small Studio credit. Choose a placement and size that fit the lesson.
- Keep private inputs in `sources/`. Cite public references where useful and keep raw private uploads out of the page.
- Keep Manim source in `scenes/`. If video or audio helps, render it to `site/video.mp4` or `site/audio.mp3` and reference the matching relative path.

Check the lesson on a phone and try its main activity before handing it back. Studio saves checked files to the private lesson repository's `main` and handles publication.
